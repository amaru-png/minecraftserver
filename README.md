# Amaru's *Minecraft: Java Edition* Server Guide
*For Naomi*
## Intro
Welcome! This (kinda) short guide is meant to help you put together your very own Minecraft: Java Edition server. This guide is intended for people with little to no technical background and is comprised of a handful of different pages to walk anyone through building their first server, step-by-step.
## Why This Guide?
Tutorials can be super confusing and tend to be bloated with unnecessary jargon. This guide is meant to be very straightforward, with as little Command Prompt interaction as possible and copy/pasted commands when necessary. The console can be intimidating for first-time users, so this guide is also intended to warm people up to its usage. That being said, this guide is specifically meant for Windows at the time of writing (5 Oct 2026).
If you're looking for a less-opinionated, more "complete" version of this guide, check out Minecraft's official wiki on the subject here:<br>
https://minecraft.wiki/w/Tutorial:Setting_up_a_Java_Edition_server

This guide is a work in progress! If you have any questions, feel free to leave a comment :)
